# Feeding-circuit pathways (AIN / ASI / AVK → pharynx)

A worked CIRCE analysis: using SPARQL over the knowledge graph to turn a whole-brain imaging
correlation (Atanas et al. 2023) into concrete, testable molecular hypotheses about how the
extra-pharyngeal "feeding" neurons AIN, ASI, and AVK could reach the pharynx.

**Read the write-up:** [`article.md`](article.md) — manuscript-form article (abstract, methods,
results, four hypotheses, references).

## Contents

| Path | What it is |
|------|------------|
| [`article.md`](article.md) | The publishable write-up. |
| [`queries/`](queries/) | The method — five self-contained SPARQL queries, one per result. |
| `run_queries.py` | Loads `outputs/connectome.ttl` (embedded Oxigraph) and runs every query. |
| `results.json` | Machine-readable query outputs (regenerated by the runner). |

The queries, in order: `01` baseline pharyngeal-projection ranking · `02` AVK↔AIN/ASI proximity ·
`03` the specific peptide channels + affinity · `04` channel specificity · `05` MC/M3/M4/AIN circuit.

## Reproduce

```
uv run cckg build && uv run cckg export                    # -> outputs/connectome.ttl
uv run python analysis/feeding_pathways/run_queries.py     # runs all queries -> results.json
```

Each `.rq` also runs unchanged against a live CIRCE SPARQL endpoint, e.g.:

```
curl -s "$CIRCE_SPARQL/query?format=json" \
  --data-urlencode "query=$(cat analysis/feeding_pathways/queries/03_feeding_np_channels.rq)"
```

Results are deterministic (every query has an `ORDER BY`; output is independent of `PYTHONHASHSEED`).
